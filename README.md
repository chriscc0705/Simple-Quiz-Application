# Simple-Quiz-Application
Simple Quiz Application is a lightweight Java application for creating, delivering, and grading short quizzes. It’s designed for learning, practice, and quick assessments — no setup or server required beyond a Java Runtime.

Key points
- Built with Java and runs on the JVM.
- Supports simple multiple-choice and short-answer quizzes.
- Shows immediate scoring and feedback to learners.
- Small, easy-to-read codebase intended for learning and extension.

How to use
1. Launch the application with a Java runtime (e.g., `java -jar SimpleQuizApp.jar`) or run from your IDE.
2. Create or load a quiz, answer the questions, and view your score and feedback at the end.
3. Extend or modify the quiz formats and UI as needed — the codebase is intentionally simple to make learning easy.
